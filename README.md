# Sébastien Palcoux — academic website

Published at https://sebastienpalcoux.github.io/ using GitHub Pages from the root of `main`.

This repository contains the deployable static website. Edit its readable HTML directly; shared styles and interactions live in `assets/style.css` and `assets/site.js`. No build step or runtime dependencies are required. Keep `.nojekyll` in place.

The main pages are Research, Publications, AI-assisted work, Teaching, Talks, and CV; the name in the header links home. Historical fusion-ring material is preserved at `/research/archive/`, and the detailed academic profile at `/cv/full/`. The existing aliases and publication anchors remain available.

The 24 regular publication records and two Hexagon releases have separate pages and BibTeX downloads. AI-assisted work is listed at `/ai-assisted/`; its citation data is in `assets/ai-assisted.json`, and its bibliography is `ai-assisted.bib`. All summaries, course materials, and research resources are retained. Publications use one chronological list with search and individually expandable summaries. Existing `q`, `area`, and `status` query links remain supported.

The independent classification website under `/grothendieck-ring-classification/` retains its own repository and publishing configuration.

The former WGT release link under `/works/#paper-hexagon-2611-00233` forwards to its entry on the AI-assisted work page. Without JavaScript it lands on a visible link to that page.
