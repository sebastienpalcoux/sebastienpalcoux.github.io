# Sébastien Palcoux — academic website

Published at https://sebastienpalcoux.github.io/ using GitHub Pages from the root of `main`.

This repository contains the deployable static website. Edit its readable HTML directly; shared styles and interactions live in `assets/style.css` and `assets/site.js`. No build step or runtime dependencies are required. Keep `.nojekyll` in place.

The main pages are Research, Publications, Teaching, Talks, and CV; the name in the header links home. Historical fusion-ring material is preserved at `/research/archive/`, and the detailed academic profile at `/cv/full/`.

Publications contains all 26 records: 24 journal articles and arXiv preprints, followed by the two Hexagon manuscripts in the open AI-assisted publications subsection at `/works/#ai-assisted`. Links at the top of Publications and the homepage open this subsection. The homepage connects the WGT manuscript's dimension and rank restrictions to the guiding question.

Search, citation data in `assets/publications.json`, and the `publications.bib` download cover all 26 publications. `assets/ai-assisted.json` and `ai-assisted.bib` retain the two-entry subset. Individual citations and existing `q`, `area`, and `status` links remain supported.

The former `/ai-assisted/` page redirects to the Publications subsection, preserving manuscript fragments. Existing `/works/#paper-hexagon-2611-00233` links now open the manuscript directly on Publications.

The independent classification website under `/grothendieck-ring-classification/` retains its own repository and publishing configuration. All course materials, historical resources, and regular publication records are retained.
